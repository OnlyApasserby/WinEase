============================================================
 WinEase —— 安装说明与已知边界
============================================================

【怎么装】
  双击 winease-setup-*-x64.exe 即可。
  · 默认装到 D:\WinEase —— 数据盘根目录普通用户就能建目录，**不需要管理员权限**
  · 本机**没有可用的 D 盘**时，安装器会自动回退到 C:\Program Files\WinEase
      （严格说是 %ProgramFiles%\WinEase；盘符不存在、未挂载、或 D 盘是光驱都算"不可用"）
      ⚠ 系统目录只有管理员能写：这种情况请右键安装程序 →「以管理员身份运行」，
        否则安装器会报「权限不足」并告诉你两种解决办法（提权运行 / 用 --dir 换目录）
  · 想装到别处：winease-setup.exe --dir "E:\Tools\WinEase"
  · 只看"本机会装到哪儿"（只读，什么都不装）：winease-setup.exe --default-dir
  · 装完会在开始菜单建一个快捷方式，并在「设置 → 应用 → 已安装的应用」里登记
  · 命令行：winease-setup.exe --dir <目录> [--launch] / --uninstall --dir <目录>

【为什么不需要额外装任何东西】
  安装包里已经带了：
  · Qt 运行库与插件（platforms / imageformats / styles / tls）
  · VC++ 运行库（应用本地部署：msvcp140.dll、vcruntime140.dll、concrt140.dll …）
  · .NET 8 运行库（随包附带，供"硬件监控"桥接使用）—— **无需预装、无需联网**
  安装过程不下载任何东西，断网也能装。

【首次使用可能遇到的两件事（都是 Windows 的正常提示，不是故障）】
  1. 「Windows 已保护你的电脑」（SmartScreen）
     本安装包**没有做代码签名**（个人项目没有购买证书），Windows 会对未知发布者
     给出警告。核对来源无误后可选「更多信息 → 仍要运行」。
  2. 使用「局域网文件传输」时，Windows 防火墙会询问是否允许联网
     该功能需要监听 TCP 端口（默认 8720）与 UDP 27127 做设备发现。
     只在**自家局域网**里勾选「专用网络」即可；公共 Wi-Fi 上请不要启用本功能。

【已知边界（如实说明，不藏）】
  · CPU / 主板温度需要以**管理员身份运行** WinEase（硬件库要读内核级的 MSR / SuperIO）。
    不满足时面板会写「无读数（需要管理员权限）」，**不会显示 0°C 冒充读数**。
    GPU 温度不需要管理员权限。
  · 局域网传输是**明文 HTTP、无鉴权**，仅供自家局域网内互传文件。
  · 卸载：从开始菜单或「已安装的应用」里卸载，也可以运行
    winease-setup.exe --uninstall --dir "<安装目录>"
    ⚠ 卸载前请先退出 WinEase（正在运行的程序会占住文件，导致删不掉）。
